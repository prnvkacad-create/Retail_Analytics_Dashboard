# Retail_Analytics_Dashboard

Blinkit Retail Analytics Dashboard Project

The dataset consists of multiple related tables which together represent a simplified version of a retail business workflow.

Dataset Description
The dataset includes the following files:

blinkit_customers.csv: Contains customer information including segmentation (Regular, Premium, New, Inactive)
blinkit_customer_feedback.csv: Includes customer ratings, feedback categories, and sentiment (positive, negative, neutral)
blinkit_orders.csv: Order-level data including order value and transaction details
blinkit_order_items.csv: Product-level breakdown of each order
blinkit_products.csv: Details of products and categories
blinkit_delivery_performance.csv: Delivery status data such as on-time and delayed orders
blinkit_marketing_performance.csv: Campaign data including spend, impressions, clicks, and conversions
blinkit_inventory.csv: Inventory data including stock levels, damaged stock, and product availability
These tables are connected and can be used together for end-to-end analysis.

Dashboard and Analysis
A Power BI dashboard has been built using this dataset. The analysis is divided into four main sections:

Customer Insights:
Focuses on customer segmentation, registration trends, and feedback analysis to understand user behavior and satisfaction.

Order Insights:
Covers total orders, revenue trends, product performance, and delivery status to evaluate overall business performance.

Marketing Insights:
Analyzes campaign performance using metrics like impressions, clicks, conversions, and return on ad spend.

Inventory Insights:
Tracks stock levels, damaged inventory, and product-level metrics to understand inventory efficiency and stock management.

Key Observations
The dataset includes around 2,500 customers distributed across different segments
Total revenue is approximately 11 million based on order data
Delivery performance shows a majority of orders completed on time with some delays
Marketing campaigns show consistent performance across different channels
Inventory data highlights variation in stock levels and damaged units across products
